# Contributing to QRF-ImageOnMap

Describe the problem and how to reproduce it. Use synthetic examples and redact credentials, player identifiers, and learner records before sharing logs or screenshots.

Work on a branch and keep each pull request focused. Run mvn verify with the project JDK. Include the results and any compatibility or migration implications in your pull request.

Preserve third-party notices and identify the source and license of imported material. Follow the project code of conduct. Report security issues privately to a maintainer before posting technical details publicly.
